# Upethma Thasangi – e-Portfolio

Personal e-portfolio website (HTML, CSS, JavaScript) for **SC1172: Introduction to Information Technology**.

**Live site:** https://upethma.github.io/

## Sections
- About Me (short paragraph + photograph)
- Work & Academic Experience
- Educational Qualifications (Secondary & Higher Education)
- Other Professional Qualifications
- Academic Projects & Practicals
- Other Skills
- Hobbies & Interests
- Downloadable Resume (PDF)
- Contact Details

## Structure
```
index.html      main page
css/style.css   styles
js/main.js      animations & interactions
images/         photographs
```

## Publish on GitHub Pages
1. Create a repository named `GITHUB_USERNAME.github.io`
2. Upload all files in this folder (keep `index.html` in the root)
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`
4. Visit `https://GITHUB_USERNAME.github.io/`
